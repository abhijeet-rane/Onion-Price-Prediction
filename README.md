# Onion Price Predictive Dashboard (OPPD)

A predictive analytics platform built with Streamlit and Machine Learning to forecast onion prices dynamically and aid in FRP (Fair Remunerative Price) planning.

## 🚀 Setup & Execution

You can run this project locally using basic `pip`, the faster `uv` package manager, or deploy it directly to the cloud.

### Prerequisites
Ensure the following files are present in the same directory as `app.py` before running:
1. `onion_weather_data.csv` (Historical dataset)
2. `weather_model.pkl` (Generated by running the Jupyter notebook)
3. `price_model.pkl` (Generated by running the Jupyter notebook)
4. `label_encoders.pkl` (Generated by running the Jupyter notebook)

*(Note: Provide a `requirements.txt` file containing the necessary packages like `streamlit`, `pandas`, `numpy`, `scikit-learn`, `xgboost`, `plotly`, and `python-dateutil`)*

---

### Option 1: Running Locally (Standard pip)

1. Create a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On Linux/Mac:
   source venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   streamlit run app.py
   ```

### Option 2: Running Locally (Using uv - Faster)

1. Install `uv` if you haven't already:
   ```bash
   pip install uv
   ```
2. Create a virtual environment using `uv`:
   ```bash
   uv venv
   # On Windows:
   .venv\Scripts\activate
   # On Linux/Mac:
   source .venv/bin/activate
   ```
3. Install dependencies blazingly fast:
   ```bash
   uv pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   streamlit run app.py
   ```

---

### Option 3: Deploying on Streamlit Community Cloud

1. Create a GitHub repository and commit all required files (`app.py`, `requirements.txt`, the `.pkl` artifact files, and the dataset `.csv`).
2. Go to [Streamlit Community Cloud](https://share.streamlit.io/).
3. Click on **New app**.
4. Authorize with your GitHub account if prompted.
5. Provide the repository, branch, and select `app.py` as the main file path.
6. Click **Deploy!**

Your application will be live in a few minutes and accessible via a public URL.
